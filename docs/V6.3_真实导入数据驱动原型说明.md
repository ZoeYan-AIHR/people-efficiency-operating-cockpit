# V6.3 真实导入数据驱动原型说明

V6.3 在 V6.2“导入—口径确认—对账—发布”演示的基础上，进一步实现了浏览器离线读取标准 `.xlsx` 模板、按真实行数据执行 P0/P1 校验、发布同源数据批次并刷新看板。

## 已实现

- 本地 `.xlsx` / `.csv` 文件读取；
- 浏览器原生 ZIP 解压、共享字符串、工作表和单元格值解析；
- `01` 至 `07` 标准数据工作表识别；
- 人力、成本、业务产出、过程质量、目标标杆的字段映射预览；
- P0 阻断与 P1 提醒；
- 公式型 `labor_cost_total` 按成本构成实时重算；
- 发布批次、指标版本、组织版本和数据质量展示；
- 经营总览、人均效能看板、组织地图和预测基线同源刷新；
- 历史样本少于 12 个月时，预测自动降级为趋势观察。

## 标准模板实测

- 工作表：10 张；
- 数据记录：15 条；
- 共同期间：2026-06、2026-07；
- P0 阻断：0 项；
- P1 提醒：0 项；
- 数据质量：99 分（原型算法）；
- 2026-07 集团汇总：FTE 107、确认收入 1,450 万元、经营利润 182 万元、全口径人工成本 769.4 万元。

## 边界

V6.3 是离线原型，不替代正式后端导入服务、数据仓库、权限审计、财务科目映射或模型训练平台。正式上线仍需冻结 FTE、人工成本、组织版本和共享分摊口径。
