# V6.6.1｜用户确认原型基线说明

## 基线确认

本仓库以用户确认的 `人效经营驾驶舱.html` 为唯一前端原型发布基线，版本号为 **V6.6.1**。

该版本整合并覆盖此前的 V6.2 / V6.3 原型发布入口。历史版本仅作为内部迭代参考，不应作为 GitHub Pages 的默认 `index.html`。

## 已包含能力

- 经营总览：经营四问、角色视图、组织风险、行动闭环；
- 投入产出分析：每万元薪酬投入净回款 / 经营利润、E/R 预测管控、经营业务、创新业务、支撑组织效能；
- FineBI 风格人均效能看板：工资贡献、人工成本构成、组织对比与趋势；
- 组织人效地图、岗位 / 项目效能、过程协同效能；
- 预警与行动闭环；
- 经营预测、情景模拟、模型治理与预测行动；
- 指标配置与行业适配；
- 本地 XLSX / CSV 读取、字段映射、M1 口径确认、P0 / P1 对账和本地发布数据批次。

## 发布注意事项

- `index.html` 与 `prototype/人效经营驾驶舱_M1真实导入数据驱动原型_V6.6.1.html` 内容一致；
- GitHub Pages 默认从根目录 `index.html` 发布；
- 标准模板与示例报告为演示资产；不要上传任何真实员工、薪酬、绩效、客户、项目、财务明细或凭证；
- 当前单文件原型包含历史迭代过程中保留的函数覆盖 / 重复声明结构。现代浏览器可按后定义覆盖执行；如进入生产代码化阶段，建议重构为模块化源码以消除重复定义。
